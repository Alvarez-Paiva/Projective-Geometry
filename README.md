# Projective Geometry · Géométrie projective · Geometría proyectiva

An interactive course on projective geometry by Juan Carlos Álvarez Paiva
(Laboratoire Paul Painlevé, Université de Lille).

**Website:** https://alvarez-paiva.github.io/Projective-Geometry/

| Folder | Contents |
| --- | --- |
| [`inaugural-lecture/`](inaugural-lecture/) | The inaugural lecture (2001, web edition 2026) in English, French and Spanish, with twelve live constructions in CindyJS. |

The book is in preparation.

## Publishing

The site is served by GitHub Pages from the `main` branch, root folder
(Settings → Pages → Deploy from a branch → `main` / `/ (root)`). Everything is
static HTML; there is no build step on GitHub. To edit the lecture, see
[`inaugural-lecture/README.md`](inaugural-lecture/README.md).
